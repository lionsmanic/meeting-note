開會拍照速記

拍下投影片，在照片旁手寫或打字，AI 再整理成筆記；最後彙整整場的重點與提問，匯出 PDF 或 PowerPoint。

還沒設定 Gemini API key，拍照與註記可以先做，辨識要等設定之後。
    還沒有場次。按下方「拍照」就會開一場並打開相機。

    ‹ 所有場次
      這一場還沒有照片。按下方「拍照」開始，可以連續拍；「錄音」可以整場邊錄邊拍；錄影在相機畫面裡切換；「相簿」可加入照片或影音檔；「手寫頁」是一張空白紙。
      拍完之後按「彙整演講筆記」。還沒辨識的照片會先自動辨識，再依主題整理成一份筆記。
      依這一場的投影片和你的註記，擬出 Q&A 可以舉手問的問題。每題有中文和英文兩版，都是可以照著念的完整句子。演講還沒結束也可以先擬，拍到新的投影片再重擬。

      設定

      只存在這台裝置的瀏覽器裡，不會寫進 GitHub。到 Google AI Studio 建立；Gemini 3.1 Pro 的 API 沒有免費額度，專案要先開啟計費。 預設 gemini-3.1-pro-preview。Google 改版時在這裡換掉即可。
      有填的話，提問的開場白會帶上這句自我介紹；沒填就只有一句感謝。
      手機內建相機畫質最好，存進相簿的是相機原始檔，但每張要多按一次「使用照片」。網頁內相機存的是拍到的原始畫面，不壓小。 寫完註記、離開那一張時自動送出，手寫和打字會一起交給 AI；連拍或從相簿加入的則拍完就送。關掉就改成自己按「AI 生成筆記」。 iPhone／iPad 的瀏覽器不能自己寫入「照片」：拍完在註記畫面上方按「存到相簿」，再點分享選單的「儲存影像」。Android 每拍一張會自動下載到相簿的 Download。從「相簿」加入的照片不會重複存。

      匯出這一場

      PowerPoint、PDF、HTML 都包含彙整筆記、提問、每張照片（含手寫）和逐張筆記。PDF 會開啟列印畫面：電腦選「儲存為 PDF」，iPhone／iPad 按列印畫面最上方的分享圖示再選「儲存到檔案」，Android 在印表機選「另存為 PDF」。
